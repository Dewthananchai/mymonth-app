## ✨ ไฮไลท์ฟีเจอร์เด่นในเวอร์ชัน 2.0

1. **🔐 ระบบล็อกอิน & สมาชิก (Authentication)**
   - รองรับ Email/Password พร้อมแสดง/ซ่อนรหัสผ่าน [👁️]
   - ปุ่มล็อกอินด้วย Google (OAuth 2.0)
   - ฟังก์ชัน "จดจำฉัน" (Remember Me) และ "ลืมรหัสผ่าน?"
   - กล่องกรอก "เข้าร่วมด้วยรหัสห้อง" (Room Code เช่น `ROOM2026`)
   - ปุ่ม Quick Demo Logins สำหรับทดสอบบัญชี `ดิว (Admin)` และ `ป๊อบ (Member)` ได้ทันที

2. **💰 ระบบบันทึกรายจ่าย (Personal & Shared Expenses)**
   - สลับประเภทระหว่าง **รายจ่ายส่วนตัว (เฉพาะฉัน)** และ **รายจ่ายร่วม (แชร์ห้อง)**
   - เมื่อเลือก "รายจ่ายส่วนตัว" ระบบจะซ่อนส่วนแบ่งค่าใช้จ่ายให้อัตโนมัติ
   - รองรับการอัปโหลดไฟล์สลิป/ใบเสร็จ (JPG, PNG, PDF)
   - แท็ก (`#จำเป็น`, `#ค่าบ้าน`), โน้ตบันทึก และรายจ่ายประจำซ้ำทุกเดือน

3. **🔀 ระบบแบ่งค่าใช้จ่ายอัจฉริยะ (Smart Split 5 รูปแบบ)**
   - **1. แบ่งตาม %:** ปรับเปอร์เซ็นต์ → ระบบคำนวณจำนวนเงินให้อัตโนมัติ
   - **2. แบ่งครึ่ง:** กดปุ่มเดียว 50/50
   - **3. กำหนดเงินเอง:** ปรับจำนวนเงิน → ระบบคำนวณเปอร์เซ็นต์ให้อัตโนมัติ
   - **4. คนเดียวจ่ายเต็ม:** เลือกสมาชิกคนนั้นจ่าย 100%
   - **5. ปุ่มลัด Quick Select:** `50/50`, `60/40`, `70/30`, `80/20`, `90/10` + แถบ Slider ลากปรับค่าได้อิสระ

4. **📊 หน้าสรุปภาพรวม (Dashboard)**
   - แถบเปรียบเทียบสัดส่วน รายจ่ายส่วนตัว vs รายจ่ายร่วม
   - เปรียบเทียบกับเดือนที่แล้ว (+5%)
   - สรุปงบประมาณรวมและสถานะการใช้จ่าย (เปรียบเทียบการใช้งาน)
   - การ์ดสรุปรายจ่ายส่วนตัวของฉัน และการ์ดรายจ่ายร่วมของห้อง

5. **💸 ระบบสรุปหนี้ & 📱 QR Code พร้อมเพย์**
   - คำนวณยอดหนี้สุทธิ (Net Debt Calculation) ของสมาชิกในห้อง
   - สร้าง **QR Code พร้อมเพย์มาตรฐาน EMVCo** โดยคำนวณ Checksum CRC16 ถูกต้อง 100%
   - แสดง PromptPay ID, ชื่อผู้รับ, จำนวนเงิน และหมายเหตุ
   - ปุ่มยืนยันการโอนเงินคืน (Settlement Confirmation)

6. **📄 ระบบบิล & 📋 คัดลอกบิลเป็นรูปภาพ (Copy as Image)**
   - แสดง QR Code พร้อมเพย์ที่มุมบนขวาของบิล
   - **ปุ่ม "📋 คัดลอกบิลเป็นรูปภาพ":** แปลงบิลเป็นภาพ PNG แล้วคัดลอกลง Clipboard ทันที เพื่อนำไป Paste ใน LINE, Facebook Messenger, WhatsApp ได้ทันที
   - ปุ่มปริ้นบิล (A4 Receipt Layout)
   - ปุ่มดาวน์โหลด PDF และส่งออก Excel (.xlsx) / CSV

7. **💰 ระบบงบประมาณ (แก้ไขได้ตลอดเวลา + บันทึกประวัติ)**
   - ตั้งและแก้ไขงบประมาณรายหมวด
   - บันทึกประวัติการแก้ไขทุกครั้ง (`budget_histories`) พร้อมเวลา, ผู้แก้ไข, ผลต่าง (+/-) และหมายเหตุ
   - แจ้งเตือนสถานะงบประมาณ: ✅ ยังเหลือ, 🟡 ใกล้เต็ม (80%), 🔴 หมดแล้ว/เกินงบ (100%)
   - ปุ่มคัดลอกจากเดือนก่อนหน้า (Copy from previous month)

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

### 1. ติดตั้ง Dependencies
```bash
# ติดตั้ง Backend dependencies
npm install

# ติดตั้ง Frontend dependencies
cd client
npm install
cd ..
```

### 2. รันแอปพลิเคชัน
```bash
# รันทั้ง Backend (Port 5000) และ Frontend (Port 3000) พร้อมกัน
npm run dev
```

หรือรันแยก Terminal:
- **Terminal 1 (Backend):** `npm run server` (http://localhost:5000)
- **Terminal 2 (Frontend):** `npm run client` (http://localhost:3000)
